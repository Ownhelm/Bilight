# Bilight for iPhone

最低支持 iOS 17。安装后独立运行，不需要 Mac 或 Docker 保持开启。首页只有搜索框，底部进入关注动态，没有推荐、热搜和自动连播。

## 构建与安装

用支持 iOS 17 及以上的 Xcode 打开 `Bilight.xcodeproj`。选择 **Bilight → Signing & Capabilities**，开启自动签名，选择自己的 Apple Team，再把 Bundle Identifier 改成自己的唯一标识。仓库没有预置个人 Team 或签名资料。

选择已连接的 iPhone，点击 Run。首次运行需要按 iPhone 提示启用开发者模式，并在“设置 → 通用 → VPN 与设备管理”中信任对应开发者；Apple ID 和安全验证由本人在 Xcode 完成。个人账号签名的有效期以 Xcode 提示为准，过期后重新构建安装即可。

启动后点左上角头像，在 App 内完成 B 站官方登录。登录状态安全保存在这台 iPhone，不需要复制电脑或浏览器中的 Cookie。

目前需要从源码构建并签名安装，暂未提供 App Store 或 TestFlight 版本；未签名 IPA 不能直接安装。

## 日常使用

**搜索。** 输入关键词、视频链接或 BV 号，查找视频和 UP 主。点进 UP 主主页可以浏览投稿、合集和列表，也可以关注或取消关注。

**关注。** 按时间浏览已关注账号的视频、文字、图文、转发和专栏摘要。下拉刷新最新内容，向下浏览继续加载；从视频或 UP 主主页返回时，保留已加载内容与浏览位置。图文可展开全文，点图片查看大图。

**我的账号。** 点顶部头像查看关注的人、收藏、下载和常访问的 UP 主；顶部另有下载和历史入口。常访问的 UP 主与观看历史都来自 B 站账号，实际播放后同步进度，打开历史可继续观看。

## 播放与下载

点开视频或手动切换分 P 后自动播放，播放结束停止。双击画面左侧后退10秒，双击右侧前进10秒；点击右下角按钮进入或退出全屏。竖屏视频支持竖屏全屏，转动手机后转回竖屏仍保持全屏，也可以下拉画面退出。轻点画面显示或隐藏控件，弹幕会避开灵动岛和刘海。

画质、倍速、字幕和弹幕都在播放器齿轮设置中。首次使用可用的最高画质，之后恢复手动选择；视频不支持该档位时使用较低画质，下次支持时恢复原选择。字幕有可用轨道时默认开启并优先中文；弹幕首次关闭，之后记住开关，重启 App 后仍保留。评论默认展开，评论与弹幕均只读。

轻点点赞切换状态，长按点赞蓄力完成一键三连，中途松开或移开取消。投币可选择数量及同时点赞，投币后不可撤回；收藏可选择或新建收藏夹。

操作栏最右侧为下载按钮。下载完成后可在 App 内离线观看，也可通过系统分享菜单导出文件；视频权限和可用画质以当前 B 站账号为准。

## 使用限制

目前聚焦普通 UP 主视频，不支持直播和番剧。会员、地区及平台限制仍然适用；同步观看历史需要登录和联网，失败时会显示提示。
