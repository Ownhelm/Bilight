# v0.1.10 · Android 收藏读取修复

本次为 Android 开发预览版更新。

## 我的收藏

“我收藏的”按平台返回的真实类型区分收藏夹与合集，打开合集时读取对应的合集视频接口，并验证创建者和合集编号，修复部分条目打开后提示“B站返回的数据不完整”的问题。

目录中的不完整条目单独显示错误并提供重新读取入口，其余正常收藏继续展示。失效、缺少创建者或暂不支持的条目明确提示不可用；平台请求本身失败时保留实际错误与重试入口。

## 安装与升级

Android 8.0 及以上下载 `Bilight-v0.1.10-android-preview.apk`，内部构建号 13，沿用原预览版签名，可覆盖同一来源的旧版安装。APK 为关闭调试的 Release 构建，建议升级前先导出重要的离线文件。

完整源码为 `Bilight-v0.1.10-source.zip`，附件校验值见 `SHA256SUMS.txt`。源码包同时包含此前已合入主分支的网页播放源与重复分P操作修复。

本次未重新打包 iPhone，未签名 IPA 继续使用 [v0.1.9](https://github.com/Ownhelm/Bilight/releases/download/v0.1.9/Bilight-v0.1.9-iOS-unsigned.ipa)。

## 验证范围

Android 86 项 JVM 回归和 3 项隔离模拟器 Compose 界面回归通过，覆盖收藏夹／合集分流、异常条目、归属验证、分页及失败重试。已用 Bilight 自身登录在安卓真机正式界面核对收藏目录、一个收藏合集及一个自建收藏夹，均能读取；真机检查不代表所有收藏内容及机型均已验收。

网页／API 168 项测试及生产构建通过。本次未代替用户进行真实点赞、投币、收藏或关注。
