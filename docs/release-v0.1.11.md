# v0.1.11 · 动态点赞与关注搜索修复

本次为开发预览版更新，提供 Android APK、iPhone 未签名 IPA 和完整源码。

## Android 动态点赞

修复关注信息流滚动后，点赞状态更新可能触发界面节点异常并闪退的问题。点赞后立即显示已点赞并将数量加一，取消点赞立即减一；失败恢复操作前的状态和数量，成功后采用平台确认的实际总数。列表与动态详情共用状态，仍保持写前校验、单次提交和账号隔离。

## 关注搜索与浏览恢复

包含当前主分支的关注名单搜索和浏览位置保留：手机关注名单支持名字、拼音与首字母匹配，并使用账号隔离的本地加密快照；网页与手机从视频返回时保留已加载页面和位置。

Android 拼音转换改用兼容最低系统版本的本地实现，修复 Android 8／9 的 API 兼容性检查错误。最低支持版本保持 Android 8.0。

## 安装与升级

Android 下载 `Bilight-v0.1.11-android-preview.apk`，内部构建号 14，为关闭调试的 Release 构建，沿用原预览版签名，可覆盖同一来源的旧版安装。

iPhone 下载 `Bilight-v0.1.11-iOS-unsigned.ipa`，内部构建号 12，须自行签名后安装；未提供 App Store 或 TestFlight 分发。完整源码为 `Bilight-v0.1.11-source.zip`，附件校验值见 `SHA256SUMS.txt`。

## 验证范围

Android 96 项 JVM 回归、9 项隔离模拟器界面回归、Debug／Release lint 和 Release 构建通过，覆盖滚动后的点赞、延迟响应、成功确认、失败回退、数量校正及真实拼音转换。iOS 归档成功，144 项测试中 4 项按环境跳过，其余通过。网页／API 172 项测试、生产构建、仓库边界和品牌检查通过。

自动化验证未使用真实账号进行点赞、投币、收藏或关注；模拟器和构建通过不代表所有设备与真实账号均已验收。

Bilight 并非哔哩哔哩官方客户端。内容访问仍受账号权限、地区及平台规则限制。
