# v0.1.8 · 分享与互动修复、网页弹幕优化

本次合并手机端修复及现有 Docker 网页端的弹幕改动，继续以开发预览版发布。

## 手机分享与互动

修复 iPhone 从账号页面进入视频后，转发面板被账号页面遮挡、点击没有反应的问题。复制链接、取消和系统分享均在当前页面上方呈现，仍只提供站外分享，不包含二维码。

修复 iPhone 与 Android 点赞后投币、收藏变灰且无法点击的问题。投币与收藏入口独立可用，互动状态确认后立即解除提交忙碌状态，公开总数在后台刷新。实际写入继续串行核验，避免重复投币、重复收藏及旧响应覆盖新状态；总数读取失败不伪造计数。

## 网页与 Docker 弹幕

合并本机 Docker 已使用的弹幕引擎修订：滚动速度提供极慢、较慢、适中和较快四档，默认适中；不同窗口宽度保持一致的滚动速度，窗口调整及暂停恢复保留弹幕位置。修复重复播放事件创建多个动画循环、异步处理与 Worker 响应串扰，以及减少动态效果设置导致弹幕瞬间消失的问题。弹幕仍只读。

本地修订引擎保留上游 MIT 许可和变更说明，详见 `src/vendor/README.md`。Docker 继续按项目现有 Compose 配置部署。

## 安装与升级

Android 8.0 及以上下载 `Bilight-v0.1.8-android-preview.apk`，内部构建号 11，沿用原预览签名，可覆盖此前同签名版本。

iPhone 下载 `Bilight-v0.1.8-iOS-unsigned.ipa`，内部构建号 10，需自行签名或通过 Xcode 安装。附件不包含个人签名、描述文件或账号数据。

完整源码为 `Bilight-v0.1.8-source.zip`，各附件校验值见 `SHA256SUMS.txt`。

## 验证范围

点赞后公开总数延迟的回归在两端均先复现失败、修复后通过。iPhone 真机通过隔离演示交互验证分享面板及点赞后打开投币、收藏；Android 使用隔离模拟器验证确认后解锁及失败回滚。测试未替用户进行真实账号点赞、投币或收藏，不代表所有机型及网络场景均已验收。
