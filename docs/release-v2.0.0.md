# Bilight 2.0.0 · 评论互动、稍后再看与播放器升级

## 1. 视频和动态都能参与讨论

iPhone、Android 和网页端都可发评论、回复楼中楼、点赞和 @ 用户。手机用底部小窗编辑，键盘弹出时仍可看到原页面。发送失败会保留草稿；如果服务器没有确认结果，需要先刷新确认，避免重复发出。

## 2. 「稍后再看」跟着 B 站账号走

三端都能从播放页加入或移除视频，也可以从账号菜单打开列表。登录同一个 B 站账号，换设备仍能看到同一份列表。视频也可复制标题和链接，或使用设备和浏览器支持的分享选项。

## 3. 手机调进度和全屏更顺手

双击画面播放或暂停。横拖画面可微调进度，拖动进度条可定位到整段视频；两种方式都先显示目标时间，松手才跳转。全屏左右两侧分别调节亮度和音量，竖屏可从中央下拉退出。播放器设置可直接切换画质、倍速、字幕和弹幕选项。

## 4. 点赞、投币和收藏的反馈更可靠

动态列表和详情共享点赞状态，连续点按会合并为最后一次选择。播放页的点赞、投币、收藏和三连会即时更新图标和对应计数，再与 B 站确认结果；写入失败时恢复已确认状态。

## 5. 下载与安装

Android 使用 `Bilight-v2.0.0-android.apk`（构建号 16，Android 8.0 及以上），沿用上一版签名。iPhone 使用 `Bilight-v2.0.0-iOS-unsigned.ipa`（构建号 14），需自行签名后安装。电脑端可使用 `Bilight-v2.0.0-source.zip`，按 README 本地运行。附件校验值见 `SHA256SUMS.txt`。
